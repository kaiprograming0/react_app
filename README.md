# React Projects

## 1. Overview

本リポジトリでは、Reactを用いたWebアプリケーションの開発・学習を行う。

React単体でのフロントエンド開発に加え、Pythonを用いたフレームワークを用いて、バックエンドと連携したアプリケーションの開発も行う。

各アプリケーションは独立したディレクトリで管理し、技術構成や実装内容を分離する。

## 3. Quickstart

### Prerequisites

- Node.js
- npm
- Python（Flask / Djangoプロジェクトで使用）
- Git

### 3.1 draganddrop-app

```bash
cd draganddrop-app

# Install dependencies
npm install

# Check available scripts
npm start
```
